## 亮点 1 ★ 注入前对抗证伪的自愈闭环（基于研究的落地创新）

**诚实定位**：反事实验证 / 对抗式 Verifier 的思想来自 2026 图+LLM SOTA 论文（F1 88.4%，ScienceDirect S1546221826005011 的 Adversarial Validation Protocol）。**我的落地创新**是把它做进**前端运行时自愈的注入循环**，并设计证伪导向 prompt + 举证责任倒置 + 否决回喂重诊断的控制流——这个具体组合业界没有。

**简历一句话**：把 AI 自愈从"注入后回归确认"升级为"注入前对抗证伪"——独立 Verifier agent 在改代码前用反事实推理推翻根因，拦截 LLM-RCA 的幻觉类比/编造证据。

**专利结构**
- **背景**：AI 自动修 bug 假阳性高（SWE-bench Verified ~24%，UTBoost 实测 15.7% 通过原测试的补丁增强后失败）。根因之一：LLM 编造证据/幻觉类比得出看似合理的错误根因。
- **现有不足**：Sentry Seer / SWE-agent / Devin / sentinel-x 验证都是**注入后回归确认**，只能发现"改了没用"，无法在**行动前**识别"诊断本身是幻觉"。
- **本方案**：诊断与注入之间插入独立 Verifier（证伪导向 prompt + 反事实推理 + 举证责任倒置），否决则替代假设回喂重诊断、先不注入；可选多 Verifier 投票。
- **有益效果**：拦截 LLM-RCA #1 失败模式（RF-01 fabricated evidence）；与注入后回归形成双层护栏。
- **权利要求**：① 诊断与行动间的独立对抗验证阶段；② 证伪导向 prompt + 反事实推理 + 举证责任倒置；③ 否决→替代假设回喂重诊断的控制流；④ 多 Verifier 投票。

## 亮点 2 ★ 自愈防污染护栏（纯原创）

**简历一句话**：针对 SWE-bench"通过测试≠真修复"，在补丁合入前做 gold-patch 污染检测（verbatim + token-Jaccard）+ 测试充分性评估，命中/不足则降级 draft 转人审。

**专利结构**
- **背景**：SWE-bench Verified ~24% 假阳性根因 = 测试不足 + 数据污染（全前沿模型逐字复现 gold patch）；OpenAI 已弃用该基准。
- **现有不足**：自动修 PR 管线普遍只跑现有测试，不评估测试是否足够、不检测污染。
- **本方案**：合入前两道确定性护栏——`assessTestSufficiency`（被改函数是否被测试覆盖）+ `detectContamination`（补丁是否复现回归集 gold patch）。任一不过 → draft + 转人审，永不自动合入。
- **权利要求**：① 合入前测试充分性启发式评估；② gold-patch 的 verbatim+近重复检测；③ 护栏与信心门禁级联降级。

## 亮点 3 ★ 确定性凌驾 AI 的信心门禁（范式切割，纯原创）

**简历一句话**：提出"AI 只做语义、确定性规则做最终门禁"——一个确定性布尔合取门禁叠在 AI 输出之上做自动应用决策；回归失败/Verifier 否决 = 硬阻断，无论 AI 自报多高。

**专利结构**
- **背景**：LLM 幻觉；用 AI 做最终放行不安全；纯规则又做不了语义 RCA。
- **现有不足**：业界"信心分"多由 LLM 自报或单阈值，AI 既诊断又放行，幻觉直通合入。
- **本方案**：分层——确定性规则 + AI 并列产出候选；确定性门禁函数 `assessConfidence` 硬布尔合取判定 high/low。**AI 不持有门禁**，回归失败/Verifier 否决 = 永不 canAutoApply。
- **权利要求**：① AI 输出与确定性门禁分层；② 硬布尔合取自动应用判定；③ 回归/Verifier 否决不可逾越阻断。

## 亮点 4 ★ LLM-RCA 残差融合（基于研究的落地创新）

**诚实定位**："残差融合"概念来自微服务 LLM-RCA 论文（23.75%→48.25%，arXiv 2602.08804）。**我的落地**：设计了具体融合公式 `融合 = √(确定性×LLM) − 0.3×残差`，Verifier 否决 ×0.3，封顶 0.9——把"确定性与 AI 分歧"本身做成降权信号。

**简历一句话**：LLM-RCA 最终置信度 = 确定性候选与 LLM 置信度的几何均值减残差惩罚，两者分歧越大越降权，让"确定性 + AI 打架"成为信号。

---

## 亮点 5 ★ 显式否决真因果的关联型根因（documented non-choice，纯原创的决策）

**简历一句话**：基于调研实证，显式选择关联型 RCA（变更关联 + 拓扑感知，封顶 0.7）并**文档化排除** SCM/do-calculus——把"不做真因果"变成有数据支撑的可防御工程决策（Datadog/Dynatrace 同样不用 SCM，但都不明说）。

## 简历 bullet 版（诚实）

- 设计**确定性×AI 混合自愈**：核心是把业界"注入后回归确认"升级为**注入前对抗证伪**（**跨 provider 独立** Verifier 反事实推理，否决则重诊断不注入），并设**确定性 GateVector 门禁**（AI 不做最终放行，回归/Verifier 否决/非局部硬阻断）——对标 2026 图+LLM+对抗验证 SOTA。
- **真实联调实证（非 demo）**：ARK doubao 诊断 + **MiniMax 跨 provider 独立 Verifier** + LLM 生成 repro 测试（未打补丁 FAIL→打补丁 PASS）+ GateVector → 真实开 GitHub PR。实测独立 Verifier 拦截了同模型 Verifier 放行的"过度泛化"补丁——独立对抗的价值实证。见 `docs/代表作留痕.md`。
- 针 SWE-bench ~24% 假阳性（测试不足+数据污染）设计**防污染护栏**（gold-patch 复现检测 + repro 红转绿替代窄测试启发式），合入前降级转人审。
- 端到端可观测四支柱：**性能（Web Vitals+LoAF+LCP归因+跨层 trace join）/ 错误（6 类+指纹分组+release 回归）/ 白屏（采样检测+因果归因）/ 行为（session-replay+沮丧信号）** —— 221 测试，极致闭环真实联调。
- 显式否决 SCM 的关联型根因（基于行业调研的可防御选型）+ 残差融合 LLM-RCA。
